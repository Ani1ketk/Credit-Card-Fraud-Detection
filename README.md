## 📂 Project Files  

- **`credit_card.ipynb`** → Training file  
  - Preprocesses the dataset  
  - Handles data imbalance  
  - Trains models like Logistic Regression, Decision Tree, and Random Forest  

- **`card.ipynb`** → Prediction file  
  - Loads the trained model  
  - Takes new transaction inputs  
  - Predicts whether a transaction is **Fraudulent** or **Legitimate**  

---

## 📊 Dataset  

The dataset used is **Credit Card Fraud Detection** from Kaggle.  

👉 Download it here: [Kaggle – Credit Card Fraud Detection](https://www.kaggle.com/mlg-ulb/creditcardfraud)  

⚠️ **Note:** The dataset (`creditcard.csv`) is not included in this repository due to GitHub’s file size limit.  
After downloading, place the `creditcard.csv` file inside the project folder before running the notebooks.
